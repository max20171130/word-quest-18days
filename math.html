初一数学提升练习 10天计划

海淀 / 黄冈风格加强版

请在纸上完成当天题目，不要看答案（本页不含参考答案）。做完后请家长把解答过程拍照发送，由老师批改并告知正确答案与讲解。

Day 1绝对值、相反数、倒数 提升（分类讨论 / 新定义）

提示：在原基础题型上加入分类讨论、新定义运算，训练「见绝对值先想符号、见新定义先套定义」的思维习惯。
练习题
  1. 已知 |x|=5，|y|=3，且 xy<0，求 x−y 的值（写出所有可能的结果）。
  2. 定义新运算：a☆b = |a−b| − |a+b|，求 (−3)☆5 的值。
  3. 已知 a、b 互为相反数，c、d 互为倒数，m 的绝对值等于 4，求代数式 m² − 3(a+b) + 2cd·m 的值（写出所有可能的结果）。
  4. 若 |a−2| + |b+3| = 0，求 (a+b)^2023 的值。
  5. 化简代数式 y = |2x−1| + |x+3|，按 x 的取值范围分三种情况讨论，并写出每种情况下化简后的结果。
  6. 求代数式 |a+2021| + |a−2020| 的最小值，并写出取得最小值时 a 的取值范围。

Day 2绝对值、相反数、倒数 专项加练（查漏补缺）

提示：Day1 批改后发现三类高频失误：①新定义运算中漏算绝对值符号；②分类讨论时把不同情况的结果张冠李戴，配对搞混；③把「乘方」当成「乘法」（如把 (-1)^2023 算成 -1×2023）。本组题是与Day1一一对应的同类型加练，前6题和后6题分别是两轮同类型训练，同类型题目请务必标清「这是第几种情况对应的结果」，每一步单独写出来，不要跳步。
练习题
  1. 已知 |x|=6，|y|=2，且 xy<0，求 x+y 的值（写出所有可能的结果，并分别标明是哪一组 x、y 对应的结果）。
  2. 定义新运算：a◎b = |a+b| − |a−b|，求 (−4)◎6 的值（写出每一步：先算绝对值里面是多少，再取绝对值，最后相减）。
  3. 已知 a、b 互为相反数，c、d 互为倒数，|m|=3，求代数式 2m² + 3(a+b) − 5cd·m 的值（写出所有可能的结果，并清楚标明 m=3 和 m=−3 分别对应哪个结果，不要配对搞混）。
  4. 已知 |a−1| + |b+2| = 0，分别求 (a+b)^2025 和 (a+b)^2024 的值，并用一句话说明这两个结果为什么不同（提示：乘方是「底数自己连乘若干次」，不是「底数乘以指数」）。
  5. 化简代数式 y = |3x+6| + |x−2|，按 x 的取值范围分三种情况讨论，写出每种情况下化简后的结果，特别注意合并同类项时符号有没有变号。
  6. 求代数式 |a+15| + |a−8| 的最小值，并写出取得最小值时 a 的取值范围。
  7. 已知 |x|=8，|y|=5，且 x、y 异号，求 x−y 的值（写出所有可能的结果，并标明是哪一组 x、y 对应的）。
  8. 定义新运算：a♦b = |2a+b| − |a−2b|，求 (−2)♦4 的值（写出每一步：先算每个绝对值里面是多少，再取绝对值，最后相减）。
  9. 已知 a、b 互为相反数，c、d 互为倒数，|n|=5，求代数式 3n² − 2(a+b) + 4cd·n 的值（写出所有可能的结果，并标明 n=5 和 n=−5 分别对应哪个结果）。
  10. 已知 |a+3| + |b−2| = 0，求 (a+b)^2027 的值；并说明如果把指数换成 2026，结果会不会一样，为什么。
  11. 化简代数式 y = |4x−8| + |x+1|，按 x 的取值范围分三种情况讨论，写出每种情况下化简后的结果。
  12. 求代数式 |a−9| + |a+12| 的最小值，并写出取得最小值时 a 的取值范围。

Day 3科学记数法与进制转化 提升（含2道乘方热身题）

提示：Day2 第10题又出现了「把乘方当乘法」的错误（(-1)^2027 算成了 (-1)²×2027），和第4题是同一个考点但做错了，说明这个概念还不够稳固，所以今天正式内容前先加2道快速热身题专门巩固一下，不用花太多时间。科学记数法与进制转化本身你已经接近满分，适当提高难度（较小数的科学记数法、五进制），保持手感即可，不必久做。
练习题
  1. 【热身】判断正误并说明理由：小宇说"(−1)^2029 = (−1)²×2029 = 2029"，这个算法对不对？请写出 (−1)^2029 的正确值。
  2. 【热身】已知 |a+7| + |b−6| = 0，求 (a+b)^2033 和 (a+b)^2034 的值，并用一句话说明为什么两个结果不同。
  3. 已知某种病毒的直径约为 0.000000102 米，用科学记数法表示为多少米？
  4. 已知 2^10=1024，将 1024 用科学记数法表示，并保留 3 个有效数字。
  5. 把十进制数 194 转化为五进制数。
  6. 把五进制数 1234₅ 转化为十进制数（请独立列式计算，不要直接使用上一题的结果作为验证依据）。
  7. 已知一个数的二进制表示为 1101₂，写出它对应的十进制数；并说明二进制、五进制、十进制的进位规则分别是什么（"逢几进一"）。

Day 4单项式与多项式概念 + 同类项 提升

提示：对应反馈表「单项式的概念」薄弱点，加入含参数的同类项判断和逆向构造问题。
练习题
  1. 若 3x^(2m)y³ 与 −5x⁴yⁿ 是同类项，求 m、n 的值，并求这两个单项式的和。
  2. 单项式 −πa²b³/3 的系数与次数分别是多少？
  3. 若关于 x、y 的多项式 3x^|m|y² − (m−2)xy + 5 是三次三项式，求 m 的值。
  4. 已知代数式 2x²−3x+1 与 ax²+bx−2 的差是一个单项式，求 a、b 的值，以及这个单项式。

Day 5合并同类项与去括号 综合提升

提示：多层括号嵌套、字母系数、新定义运算三类题型综合训练，是「去括号法则」章节的强化。
练习题
  1. 化简：3{2x − [x−2(x+1)] + 3}。
  2. 已知 A=2x²−3xy+y²，B=−x²+xy−2y²，求 3A−2(A+B) 的值，其中 x=1，y=−1。
  3. 定义新运算 a⊕b = 2a−b+1，求 (x⊕2y)⊕(3x⊕y) 的化简结果（结果用最简整式表示）。
  4. 若字母 A 表示的多项式满足 A + (3x²−2x+1) = 5x²+x−3，求 A，并指出 A 中 x² 项的系数与 x 项的系数之和。

Day 6整式加减化简求值 提升

提示：整体代入、找规律、新定义运算综合，直接对应反馈表中「整式加减化简求值」这一大类的失分点。
练习题
  1. 已知 x²+x=1，求代数式 3x²+3x+2024 的值。
  2. 已知 a−b=3，ab=−2，求代数式 a²+b²−3ab 的值。
  3. 已知多项式 2x²−3x+1 减去另一个多项式所得的差是 x²+x−2，求这个多项式，并求当 x=−2 时它的值。
  4. 观察下列等式：1²−0²=1，2²−1²=3，3²−2²=5……请你猜想第 n 个等式（用含 n 的等式表示），并用整式运算说明它成立；然后利用这个规律直接写出 2023²−2022² 的值。
  5. 定义新运算 a※b = a²−2ab+b²，求 (x+1)※(x−1) 的化简结果，并求当 x=5 时的值。

Day 7绝对值与整式综合①

提示：对应反馈表中丢分最多的「绝对值和整式综合」题型，重点练习分类讨论的规范书写。
练习题
  1. 化简代数式 y=|x−2| − |2x+1|，按 x 的取值范围分三种情况讨论，写出每种情况下的化简结果。
  2. 阅读理解：|a−b| 表示数轴上 a、b 两点间的距离。若 |x+3| + |x−5| = 8，直接写出满足条件的整数 x 的个数。
  3. 已知 |2x−3|=7，求 x 的值；并求代数式 3x−1 的所有可能取值。
  4. 若 x 满足 3<x<5，化简 |x−3| + |x−5| − |2x−6|。

Day 8绝对值与整式综合②

提示：四段分类讨论 + 整数解个数 + 最值问题，是整个10天计划里难度最高的一天，建议预留充足时间。
练习题
  1. 化简 y=|x−1| − |2x+3| + |x−4|，按四个区间（以 x=-3/2、x=1、x=4 为分界点）分类讨论，写出每一段的化简结果。
  2. 求满足 |a−1| + |a+2| ≤ 5 的所有整数 a 的值（写出所有解并简要说明理由）。
  3. 求代数式 |2x−1| + |x+2| 的最小值，并求此时 x 的取值。

Day 9阶段测试卷①（黄冈密卷风格·综合测试）

提示：本卷题型比例参照常见「密卷」结构：选择题4道、填空题4道、解答题4道、拔高题2道，共14题，建议45-60分钟内独立完成，完成后再对照答案。
一、选择题（每题3分）
  1. 下列各数中，倒数等于它本身的数是（　　） A. 0　　B. 1　　C. -1　　D. 1和-1
  2. 单项式 -2/3 x²y³ 的次数是（　　） A. 2　　B. 3　　C. 5　　D. 6
  3. 若 |a|=a，则 a 满足（　　） A. a>0　　B. a<0　　C. a≥0　　D. a为任意有理数
  4. 下列合并同类项正确的是（　　） A. 3x+2y=5xy　　B. 3x²-x²=3　　C. 2a²b-3a²b=-a²b　　D. 5m+5n=10mn
二、填空题（每题3分）
  1. 计算：(-2)³ - |-8| ÷ (-2) = ______
  2. 已知 3x^(n-1)y² 与 -x³yᵐ 是同类项，则 n+m = ______
  3. 将 -0.0000305 用科学记数法表示为 ______
  4. 化简 3a - [2a - (a-3)] = ______
三、解答题（每题6分）
  1. 计算：(-1)^2024 + |-3| - (-2)² × (1/2)。
  2. 先化简，再求值：2(x²-2xy) - (3x²-xy) + x²，其中 x=-1，y=2。
  3. 若关于 x 的多项式 (m-3)x² + (2-n)x - 5x² + 7 化简后是关于 x 的一次二项式，求 m 的值，并写出 n 应满足的条件。
  4. 某同学在计算 2A-B 时，把"2A"误看成了"A"，求得结果为 3x²-2x+1；已知 B=x²+3x-2，求正确的计算结果。
四、拔高题（每题8分）
  1. 已知 A=|a-1|+|a+3|，当 a 取不同有理数时，求 A 的最小值，并写出取得最小值时 a 的取值范围。
  2. 若 |x-2|+|y+1|=0，且 z 满足 |z|=3，求代数式 (x+y+z)² 的最小值和最大值。

Day 10阶段测试卷②（海淀期末风格）+ 错题总结

提示：本卷加入新定义阅读理解题（高斯函数）和含参绝对值方程，是10天计划中综合性最强的一套；完成后请结合Day1-9的错题，整理出自己的《易错点清单》。
一、选择题（每题3分）
  1. 计算 -3² 的结果是（　　） A. 9　　B. -9　　C. 6　　D. -6
  2. 下列说法正确的是（　　） A. 单项式-5的系数是5，次数是0 B. 多项式x²-3x+2是三次三项式 C. -a一定是负数 D. 0是单项式，但没有次数
  3. 下列各数中，最大的数是（　　） A. -(-3)　　B. -|+2|　　C. -3²　　D. (-2)²
  4. 若 a、b 互为相反数，且 a≠0，则下列结论正确的是（　　） A. a+b=0且a=b　　B. a/b=-1　　C. |a|=|b|=0　　D. ab>0
二、填空题（每题3分）
  1. 计算：|-2/3| - (-1/3) + (-2)² ÷ 4 = ______
  2. 若单项式 2x^(a+1)y² 与 -3x³y^(b-1) 是同类项，则 a-b = ______
  3. 用科学记数法表示的数 5.6×10⁴ 还原成原数是 ______
  4. 已知代数式 2x²-kx+1 中不含 x 项，则 k = ______
三、解答题（每题6分）
  1. 计算：(-1)^2023 - |2-5| + (-3) × (-2)²。
  2. 化简并求值：3(2a²-ab) - 2(3ab-a²) + a²，其中 a=2，b=-1。
  3. 阅读材料：我们规定 [x] 表示不超过 x 的最大整数，例如 [3.2]=3，[-1.5]=-2。 (1) 求 [2.9]、[-0.5] 的值； (2) 若 [x]=3，求 x 的取值范围； (3) 求 [3.5] + [-3.5] 的值。
  4. 已知关于 x 的方程 |2x-a|=3 的一个解是 x=5，求 a 的值，并求方程的另一个解。
四、拔高题（每题8分）
  1. 化简代数式 y=|x+1| - 2|x-2| + |x-3|，按四个区间（分界点 x=-1、x=2、x=3）分类讨论，并代入 x=0 验证其中一段的结果是否正确。
  2. 已知关于 x 的方程 |x-3| + |x+2| = a： (1) 若方程无解，求 a 的取值范围； (2) 若方程的解集是一段连续的实数范围（即有无数个实数解），求此时 a 的值，并直接写出这时方程的整数解有多少个。
自查清单
  • 整理Day1-10所有做错的题目，用红笔在旁边写清楚错误原因：概念不清 / 分类讨论漏情况 / 计算失误 / 审题不细致。
  • 重新默写一遍：绝对值的几何意义（表示到原点或到某点的距离）、去括号法则（括号前是负号，各项都变号）、合并同类项法则（字母不变，系数相加减）。
  • 针对分类讨论题，总结自己的标准步骤：①找所有绝对值符号里代数式的零点 → ②把零点从小到大排序、分区间 → ③在每个区间内判断每个绝对值符号内代数式的正负、去掉绝对值 → ④化简 → ⑤检查区间端点处结果是否连续（衔接处数值应相等）。
  • 把10天里出现过的所有新定义运算题（☆、⊕、※）重新翻出来看一遍，确认自己能不看答案独立复述解题思路。
